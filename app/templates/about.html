About This Project

College Placement Prediction using Machine Learning • BCA Final Year Project

Project Objective

This project uses machine learning algorithms to predict whether a college student will get placed or not based on their academic performance, skills, internships, and other relevant factors. By leveraging supervised classification models, universities and students can identify early intervention points.

Core Technologies & Libraries
Python 3.11 Pandas NumPy Scikit-learn Matplotlib Seaborn Jupyter Notebook Flask HTML5 & Vanilla CSS
✦

Target Mission

Empower undergraduate students to diagnose their placement readiness and take decisive steps towards career advancement.

Project Workflow & Machine Learning Pipeline
1. Data Ingestion & Synthesis

1,200 curated student profiles covering primary metrics: 10th percentage, 12th percentage, CGPA, internships, projects, technical skills, and active backlogs.

2. Feature Preprocessing & Scaling

Feature vectors are normalized using StandardScaler so high-variance metrics like percentages don't bias smaller scale metrics like backlog counts.

3. Model Training & Validation

Trained and evaluated 5 classification algorithms: Logistic Regression, Random Forest, Support Vector Classifier, KNN, and Decision Trees.

4. Real-time Inference Engine

Winning model deployed with Flask REST endpoints and interactive web UI for instantaneous probability scoring and personalized advisory feedback.

Examiner Viva Q&A Guide
Placement eligibility criteria in colleges are largely linear decision boundaries (e.g., meeting a minimum CGPA threshold combined with zero backlogs and internship experience). Logistic Regression fits smooth sigmoidal decision boundaries with high calibration without overfitting on smaller noise parameters.
Features like 10th percentage range from 50 to 100, while Backlogs range from 0 to 5. Without standard scaling (mean=0, variance=1), algorithms with distance metrics or weight vectors would place disproportionate emphasis on percentages.
The dataset features a realistic 64% placed to 36% unplaced ratio. Model evaluation is scored not just on raw accuracy, but on weighted F1-score, Precision, Recall, and ROC-AUC.
